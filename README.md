# Neetcode-mock

Interactive **Jupyter notebook** courses for learning Python with an eye toward **coding interviews** and **system design**. The material is inspired by [NeetCode](https://neetcode.io/) and expanded with extra sections and exercises.

Across four tracks you get **217 numbered challenges** in **36 notebooks**:

| Track | Challenges | Notebooks |
| --- | --- | --- |
| **Python for Beginners** | 93 | 13 |
| **Python for Coding Interviews** | 44 | 9 |
| **Python for OOP** | 41 | 7 |
| **Python DSA Toolkit** | 39 | 7 |

## How to use

**Option A — Run in browser (no install):** Click any **Open in Colab** link below.

**Option B — Run locally:** Clone this repo, open in **Cursor** / **VS Code** / **JupyterLab**, and run cells with **Shift + Enter**.

Each notebook has markdown explanations, starter code (with `# TODO` or `pass`), and collapsible **Show Solution** blocks.
